# Проверка MVP 0.1.1

## Поддержка разных PHP-плагинов

Обязательная зависимость ZIP — только `com.intellij.modules.platform`. Два PHP-адаптера зарегистрированы в отдельных optional descriptors: `com.jetbrains.php` и `ru.openide.openphp`. Общие индекс, настройки, кэш привязки и маркеры не импортируют классы этих поставщиков. SDK PHP-плагинов используются при компиляции и не включаются в поставку.

Матрица fixture-тестов:

| Режим | Тестовая платформа | Результат |
|---|---|---|
| JetBrains PHP 252.28539.13 | IDEA Ultimate 2025.2.6.2 / JDK 21 | 22 теста пройдено |
| PHP for OpenIDE 0.9.9, без JetBrains PHP | Raketa 2026.2.4 / 262.11879.SNAPSHOT / JBR 25 | 22 теста пройдено |
| Без обоих PHP-плагинов | IDEA Ultimate 2025.2.6.2 / JDK 21 | 13 тестов пройдено |

В первых двух режимах выполняется одна и та же suite: 12 проверок ядра и 10 проверок IDE. Это 22 проверки, выполненные в двух окружениях, а не 44 разных теста. В третьем режиме повторяются 12 проверок ядра и выполняется отдельная проверка загрузки и индексации без PHP-плагинов.

Тест выбора backend дополнительно проверяет, что активен ровно один адаптер и плагин другого поставщика не загружен. OpenIDE-адаптер проверен на классах, методах, интерфейсах, трейтах, enum, нескольких namespace, несохранённых изменениях, реальных gutter markers и навигации после сдвига строк baseline.

Для тестов Ракеты использовано локальное представление SDK, созданное `tools/prepare-local-sdk.py`: симлинки на установленную платформу, копия метаданных с распознаваемым Gradle кодом продукта и alias её штатного core descriptor для структурного анализатора SDK. Установленная IDE не менялась. Test framework — опубликованный артефакт 262.11879.100. Тесты выполнялись с настоящим PHP for OpenIDE 0.9.9, а не с mock PSI.

Текущий ZIP: `build/distributions/phpstan-baseline-highlighter-0.1.1.zip`. Внутри только JAR плагина и searchable options; сторонние PHP-плагины не упакованы. Структура ZIP проверена `verifyPluginStructure`.

Plugin Verifier 1.411 для итоговой 0.1.1 против PhpStorm 2026.3 / 263.7307.215: **Compatible**, четыре использования deprecated API, без scheduled for removal. Отчёт — `build/reports/pluginVerifier/PS-263.7307.215/report.html`. Проверку OpenIDE-адаптера подтверждают отдельные runtime fixture-тесты на Ракете; PHP for OpenIDE в проверяемой PhpStorm не установлен.

Отчёты матрицы: `build/reports/tests/jetbrains/index.html`, `build/reports/tests/openphp/index.html`, `build/reports/tests/none/index.html`. Команды для переключения backend и подготовки локального SDK приведены в `README.md`.

## Первоначальные измерения ядра 0.1.0

Проверено 13 ноября 2026 года в Linux на Intel Core Ultra 7 255H. Сборка и fixture-тесты выполнялись с JDK 21.0.12.1, Gradle 9.3.1, SDK IDEA Ultimate 2025.2.6.2 (252.28539.54) и PHP-плагином 252.28539.13. Plugin Verifier запускался через JBR 25 против локальной PhpStorm 2026.3 (263.7307.215).

### Проверки первоначальной версии

| Проверка | Результат |
|---|---|
| Unit-тесты парсера, владельцев сообщений, сопоставления и путей | 12 пройдено |
| Fixture-тесты IDE | 9 пройдено |
| Сборка устанавливаемого ZIP | Пройдена, 97 953 байта |
| `verifyPluginStructure` | Пройдена |
| Plugin Verifier 1.411, PhpStorm 263.7307.215 | Compatible |
| Все baseline соседнего репозитория Ракеты | 27 файлов, 22 209 записей, ошибок разбора нет |

Fixture-тесты проверяют маркеры класса и метода, регистрацию provider в daemon редактора, относительные пути и произвольные имена источников, несохранённые изменения baseline и PHP, удаление источника, несколько источников, отключение плагина, переход после сдвига строк, PHP PSI интерфейсов/трейтов/enum и создание/повторное открытие настроек.

Парсер проверяется на одинарных/двойных кавычках NEON, двух уровнях экранирования, Unicode, BOM/CRLF и точности диапазонов. Есть проверки ошибочного формата, дубликатов и неподдерживаемых полей. Сопоставление отличает метод-владелец от вызываемого метода, учитывает несколько классов и неизвестного владельца.

Plugin Verifier сообщает четыре обращения к API, помеченным deprecated в новой IDE: перезапуск подсветки файла, два коротких `ReadAction.compute` и открытие текстового редактора. Эти API доступны в SDK 252 и в проверенной IDE 263; совместимых с обоими SDK замен для всех вызовов в этой версии не вводилось. Обращений к API с пометкой scheduled for removal в итоговом отчёте нет. Проверка совместимости не является ручным испытанием приложения.

`verifyPluginProjectConfiguration` ранее завершился успешно с рекомендацией убрать `until-build`. Ограничение `263.*` сохранено намеренно: совместимость с будущими ветками не проверена.

### Измерения ядра

Последний прогон после прогрева:

| Показатель | Значение |
|---|---|
| Исходные данные | 27 NEON baseline, 7 612 389 байт |
| Записи / уникальные целевые файлы | 22 209 / 6 827 |
| Разбор, нормализация, классификация и создание записей | 311 мс |
| Приблизительная прибавка удерживаемой памяти записей и сгруппированного индекса | 14,1 МиБ |
| Привязка класса с 2000 методами и 1000 записями | p95 ≈ 0,91 мс, 100 прогретых измерений |

Тексты файлов были загружены до измерения. Время не включает обход файловой системы, чтение файлов, проверку существования целевых файлов, общий старт IDE и построение PHP PSI. Группировка по файлам включена в оценку памяти, но выполняется после измерения времени создания записей. Память оценивается по разнице занятой JVM-кучи после `System.gc()`; это приблизительный ориентир. Данные Ракеты могут меняться параллельно, поэтому число записей относится к этому прогону.

Микробенчмарк не измеряет полное влияние плагина на память и отзывчивость IDE. При открытии редактора используются готовый индекс и локальный кэш привязки. Фонового polling и запуска PHPStan в реализации нет.

### Команды первоначального замера

Команды для окружения с закэшированными IDEA Ultimate и PHP-плагином:

```bash
JAVA_HOME=/path/to/jdk21 ./gradlew test benchmarkBaselines buildPlugin --offline \
  -PplatformType=IU -PphpPluginVersion=252.28539.13 \
  -PbaselineDirectory=/path/to/raketa

JAVA_HOME=/path/to/jdk25 ./gradlew verifyPluginStructure verifyPlugin --offline \
  -PplatformType=IU -PphpPluginVersion=252.28539.13 \
  -PverificationIdePath=/path/to/PhpStorm
```

Без кэша удалите `--offline`. Обычная сборка `./gradlew test buildPlugin` использует PhpStorm из настроек проекта и загружает SDK при необходимости.

Актуальные отчёты 0.1.1 приведены выше. `build/reports/ui/settings.png` содержит просмотренный при разработке headless-рендер панели настроек; он обновляется fixture-тестом текущего backend. Исторические результаты 0.1.0 описывают первоначальный прогон и не являются отдельной матрицей совместимости новой версии.

## Оставшиеся проверки

Перед распространением на команду проверить оформление значков и подсказок в светлой/тёмной теме в обычной IDE, массовую смену файлов при переключении ветки, два одновременно открытых проекта и полный профиль памяти/задержек в большом проекте. Headless-рендер настроек и fixture-тесты не заменяют эту проверку. Remote Development и промежуточные версии IDE отдельно не проверялись.
